## 💻 实验环境

- **模拟器**：华为 eNSP (Enterprise Network Simulation Platform)
- **核心技术栈**：TCP/IP, OSPF, RIP, VLAN, NAT, ACL 等

## 🎯 学习目标

- 深入理解 OSI 模型与 TCP/IP 协议栈的数据转发原理
- 能够独立在 eNSP 中完成中大型网络拓扑的规划、搭建与排错
- 将网络底层知识与 Linux 系统运维相结合，为后续考取更高级别认证及从事系统网络运维工作打下坚实基础。
